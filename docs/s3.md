# S3 privado para Codi

El bucket de Codi debe tener **Block Public Access** habilitado. Los archivos se envían al backend de Nest y solamente la API usa el cliente S3; el navegador nunca recibe credenciales ni URLs de carga de S3. Las claves de objeto nunca se exponen como URL persistente.

## IAM mínimo de la API

El rol o usuario usado por la API necesita `s3:GetObject`, `s3:PutObject` y `s3:DeleteObject` sobre `arn:aws:s3:::<bucket>/*`. `HeadObject` usa el permiso `s3:GetObject`; `s3:HeadObject` no es una acción IAM. No necesita permisos de listado ni ACL públicas.

Configurá una regla lifecycle que borre `pending/` al día siguiente. Las cargas que no se adjuntan a un perfil o lesson quedan allí hasta que esa regla las elimine.
